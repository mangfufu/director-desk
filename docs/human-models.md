# 内置人物外形维护

人物外形由 `human-anatomy.ts` 的体型分布、`human-surfaces.ts` 的曲面和原有骨架共同生成。身体参数仍复用资产比例字段、性别、身高和体格，不增加工程字段。服装与体型独立组合；UI、MCP 和离线工程继续使用同一资产与参数契约。

`person`、`woman` 和群演使用原骨架尺寸，改动曲面时保留关节位置。新的人物细节追加到既有节点之后并标记为姿态辅助节点；不要把它们插到旧关节之前。服装改造通过 `reserveHumanCostumeSlots` 保留旧接拍姿态的节点路径，新服装跟随关节，不重复保存静态衣服变换。

长裙和长袍使用连续网格，按髋、大腿和膝盖变形。它不模拟布料动力学。衣摆骨架贴图随模型释放；基础人体保持在 9000 三角面预算内。群演继续共享几何体。

验证入口：`node scripts/verify-human-silhouettes.mjs` 生成同色、同身高的正侧面对比与动作采样，产物集中在 `tmp/human-silhouettes`。`verify-human-actions.mjs` 验证全部人物的基础动作采样和跳帧一致性。身高、地面接触、手持绑定、旧接拍姿态、衣摆变形及资源释放由对应测试覆盖。
