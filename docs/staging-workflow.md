# 布景编辑与复用

对象编组、对齐与阵列、用户布景库已在当前开发版实现。本次未修改发布版本号，已安装的 0.4.10 尚不包含这些新增功能。

## 使用入口

| 功能 | 操作 |
| --- | --- |
| 编组 | 在对象列表按 Ctrl/Cmd 多选，按 Ctrl/Cmd+G，或选择「编辑 → 编组」。右侧可改组名、整体平移和旋转。 |
| 选择及编辑 | 对象列表的编组下拉框选择整组；右侧「成员 → 单独编辑」调整一个成员。Ctrl/Cmd+Shift+G 解组，保留对象。 |
| 复制 | 选中整组或多个对象后按 Ctrl/Cmd+D，生成独立副本。模型与媒体源继续共享。 |
| 对齐及阵列 | 「编辑 → 对齐与阵列」。对齐选择世界轴、边界和基准对象；分布保持首尾不动；阵列可选直线、网格或环形，数量包含原件。 |
| 保存布景 | 选中对象后打开「文件 → 布景库」，填写名称并「保存当前选择」。保存路径和动作，以及必需的绑定目标。 |
| 复用及分享 | 在布景库搜索、选择条目，填写插入位置并「插入」。可用 `.staging` 文件导入／导出；文件自带实际使用的模型和媒体资源。 |

布景库保存在本机，已经插入的对象独立于库中原件。插入一次撤销即可恢复；删除库条目不删除场景对象，也不进入工程撤销历史。布景位置按 0 秒成员原点均值归零，插入位置对应此原点；需要精确落地时按实际边界对齐。

AI 使用 `director_apply` 的 `group` 操作、`director_arrange` 和 `director_staging`；离线使用 `apply`、`staging-save`、`staging-insert`。完整参数及示例见[编辑约定](../skills/director-desk/references/editing.md)。

## 当前基础

- 已有对象多选及时间轴多选、单对象变换、网格／物体边界吸附。
- 已有模块连接、手持绑定、楼层与区域。它们表达不同关系，编组不替代它们。
- 已有整个戏段的场景模板导入和资源去重，可供局部布景插入复用。
- 新增编组按戏段保存；局部布景库独立存储，通过原有场景合并规则插入。

## 开发顺序与验收

| 阶段 | 交付 | 验收依据 | 状态 |
| --- | --- | --- | --- |
| 1. 对象编组 | 多选成组、命名、选择整组、单独编辑成员、解组；整组平移、旋转和独立复制 | 保存重开与戏段隔离；成员间距／方向、路径和摄影机视线一起变换；复制引用正确；锁定失败回滚；撤销；实际拖动 | 已实现并验证 |
| 2. 对齐与阵列 | 按世界轴对齐边界／中心、等距分布、直线／网格／环形阵列 | 使用真实边界；明确基准对象；旋转／缩放后的模型可用；复制不共用可变状态；批量操作一次撤销；大数量操作不逐个重建场景 | 已实现并验证 |
| 3. 用户布景库 | 保存选中对象或整组、命名检索、插入当前戏段、重命名删除、导入导出分享 | 模型／媒体依赖完整；内部引用重映射；外部依赖明确处理；插入有独立 ID；网页／桌面可用；资源加载失败不留下半个布景 | 已实现并验证 |

## 共用契约

- 编组是戏段内的编辑组织关系，成员继续使用实体世界坐标；不为渲染器额外套一层父节点，不改变旧工程播放结果。
- 首版采用平级编组，每个对象至多属于一个组。成员可以单独编辑；选择整组才应用整体变换。组不跨戏段，不等同于区域、楼层或时间轴多片段。
- 整体变换由一个共享模块执行，UI、内置 AI、MCP 和离线工程使用同一规则。位置路径、视线等世界坐标随变换处理，局部握持偏移不当作世界坐标重复移动。
- 复制复用现有资源并生成独立对象、动作及组 ID，重映射组内目标、手持、模块、场域和摄影机引用。关联组外对象时明确保留或报错，不静默破坏关系。
- 沿用事务、revision、撤销及锁定保护；一次批量操作一次提交，避免每个成员触发完整重建。拖动不反复复制资源数据。
- 查询按需返回编组和布景元数据，不默认返回全库或模型／媒体字节。每阶段同步对应的 MCP 帮助、内置 skill 和离线工具。
- UI 使用现有对象列表、属性栏和菜单，不新增固定占满屏幕的大面板；参数使用清楚短标签。

## 范围

本轮不恢复识图自动布景，也不扩展精细人体仿真。Issue #5 的轨迹显示问题按用户要求暂不处理。其他候选功能（构图辅助、轴线、节拍标记、整体变速、镜头方案对比）尚未进入本轮实现范围。

## 验证与文档

已完成共用操作测试、实际 Chrome UI 和隔离 Electron 桌面验证，桌面经真实 HTTP MCP 调用编组、阵列和布景库。离线打包脚本已验证多戏段编组、阵列、布景保存和插入。内置 skill 按内容更新。

主要回归脚本：

```sh
node scripts/verify-groups.mjs
node scripts/verify-staging-workflow.mjs
npm run desktop:prepare
node scripts/test-groups-desktop.mjs
```

审查覆盖新增模块及各共用入口的改动，修复了异步列表刷新重新打开已关闭窗口、辅助机位误入组、对象列表选中与分页，以及大阵列反复扫描结果集的问题。布景列表只加载元数据，插入时才加载源文件；同工程内复用相同资源。

本机单次数据计算测试中，10 个方块阵列为 1,000 份（新增 9,990 个对象）由约 3.7 秒降至 0.16 秒；不包含渲染及 GPU 资源加载，不代表任意大型导入模型的操作耗时。

首版只做平级编组与平移／旋转；整体缩放需单独编辑成员。对齐使用当前帧实际几何边界，独立移动受绑定约束的对象会给出错误，不自动拆除绑定。环形阵列原件是首个位置，圆心在它沿 −X 的半径距离处。未开展 macOS 的实机验收；发布和版本号另按用户要求执行。
