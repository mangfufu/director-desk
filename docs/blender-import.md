# Blender 工程导入

入口：桌面版「文件 → 导入 Blender 工程」。默认在当前工程中新建独立戏段并切换到该戏段，保留原戏段与工程文件关联；可选加入当前戏段或作为独立工程打开。作为独立工程打开时清除文件关联，保存为 `.director`，不会覆盖 `.blend`。

## 转换契约

- 本机 Blender 4.2+；先读已保存路径，再查 PATH、Windows Blender Foundation 安装目录、Steam 默认目录与 libraryfolders.vdf、macOS 应用目录、Linux 常用安装目录。手动选择后校验版本并保存在用户配置目录。
- 独立子进程使用 `--background --factory-startup --disable-autoexec --python-exit-code 1`，仅执行随软件交付的 `export-scene.py`，`open_mainfile(use_scripts=False)`。不执行工程内嵌脚本，不加载用户启动插件，不保存源工程。
- 模型按对象导出 GLB；同一骨架绑定的网格组成一个人物对象。集合实例（含嵌套、链接集合）在后台进程中展开，每个顶层实例作为一个对象，保留子节点与实例父级动画。只有控制线或空节点、没有三角面的 GLB 不进入模型资源，按对象名称返回提示；控制对象仍留在 Blender 求值环境中，不破坏其他对象的约束。读取世界坐标，补偿导演台原有底部中心归一化，不改现有外部模型格式。骨骼和对象动画导出 SCENE 动画，按原时间范围平移到零秒，导入原生动作片段。静态对象不逐帧采样；检测本体、数据、形态键、父级、约束目标和骨架依赖，驱动器、模拟与 Geometry Nodes 保守保留动画处理。
- 材质准备由 `materials.py` 完成。保持可直接导出的 Principled／Emission；展开节点组，将旧 Diffuse／Glossy／Glass 组合转换为 PBR。图片按所属链接库解析路径，保留原图与 UV；经过颜色调整节点的图片提取为基础贴图，无法直接表达的程序纹理取基础颜色或参数近似。保留直接法线贴图，程序凹凸简化。不执行 Cycles 烘焙、不新增 UV 图集。转换仅修改后台副本，不写源工程或原图；任务目录随成功、取消或失败清理。
- 同数据／材质的网格复用转换结果；复杂对象相关着色按基础材质近似。加载后按图片编码 SHA-256 共享不可变图像 Source，纹理采样参数、材质和对象仍独立；最后一个源模型释放时才关闭图片。工程格式和原资源字节不变。
- 旧复合 BSDF 到 PBR 是外观近似，不等于完整 Cycles 着色器移植。导入定位为可编辑预演；动态程序纹理、体积、任意着色网络、间接照明和最终色彩管理不作为完整还原目标。
- 摄影机按帧求值约束后的世界位置、朝向和视场角，转换为位置路径、视线路径和焦距／倾斜／移轴通道，复用导演台 36 mm film gauge。时间轴摄影机标记变为切镜。
- 有蒙皮不等于人物：完整人形映射才归为人物，百叶窗等机械骨架保留为带原生动画的道具。人物身高参数限制不改变外部模型的源尺寸。
- 点光、聚光、面光、太阳光取起始帧。方向与颜色转换，功率按类型近似换算，外观不等同于 Cycles 渲染。
- 读取旧灯光 Emission／Light Falloff 节点中的实际强度、颜色和 Blackbody 色温，并处理曝光及面光归一化。太阳光阴影范围由源场景边界估算，避免固定超大范围损失阴影细节。
- 单位使用 Blender 场景单位比例；导出坐标转 Y 向上。FPS 和画幅映射到现有可选值，差异放入 warnings。
- 不支持正交／全景摄影机、世界节点、顶点／面实例、灯光动画；动态拓扑、任意着色节点、模拟缓存不保证完整转换。源脚本关闭造成的驱动差异不由自动运行私人脚本补救。

## 生命周期与公共入口

`desktop/blender-import/host.cjs` 负责发现、进程、进度和临时资源；`src/import/blender-project.ts` 负责格式映射；`blender-import.ts` 在原事务和 revision 检查后一次提交。UI 与 `director_import(kind:blender)` 共用该路径。MCP 通过现有 `director_job` 查询与取消；不增加新模型工具，也不执行 Agent 提供的代码。

任务目录仅在 `<userData>/blender-import/jobs/convert-*` 中创建。成功读取 GLB 包后、失败或取消后清理当前目录。Windows 仅终止本次生成的进程树；不按进程名称杀掉用户自己的 Blender。源文件、外部贴图、用户安装目录不参与清理。

转换返回轻量清单，前端按任务 ID 和索引逐个读取模型，避免把整场贴图一次性跨 IPC 复制。事务结束（含失败、取消）释放任务目录；关闭或下一次转换也清理遗留任务。图片采用 AUTO，复用源 PNG／JPEG 编码，避免每个物体重复转换为 WebP。模型文件独立可编辑，加载阶段继续共用相同图片。

## 验证

- `tests/blender-host.test.cjs`：隐藏运行参数、禁用自动脚本、进程前／过程中取消、失败清理、资源路径边界。
- `node scripts/test-blender-materials.mjs`：独立生成旧漫反射、节点组、图片、程序纹理、玻璃、金属素材；检查转换后的真实 GLB 材质和贴图、无烘焙输出、动画依赖判断，并核对源文件未修改。
- `tests/nearest-hit.test.ts`：前向包围盒裁剪／最近命中与完整射线检测对照，包括变换、隐藏、层、形变及实例。`tests/model-image-pool.test.ts`：图像共享、参数隔离、源资源释放和重新获取。
- `tests/blender-project.test.ts`：摄影机视场、倾斜、移轴、时间、FPS／画幅映射、薄片机械骨架归类与 MCP 契约。
- `tests/fixtures/blender-scene.py`：真实测试素材生成器，含独立物体、阵列、蒙皮骨骼、运镜变焦、切镜、面光、无面的控制网格及带父级动画的嵌套集合实例。生成文件只写到显式测试路径。
- `node scripts/test-blender-import.mjs`：真实桌面和 MCP 验收（先运行 `npm run desktop:prepare`，可用 `BLENDER_PATH` 指定测试程序）。生成独立样例后对照 Blender 的 18 个投影结果，检查骨骼／物体动画、切镜、保存重开、撤销、取消以及中英文 UI。
- 真实桌面验收输出集中在 `tmp/blender-import`。不得将修补某个测试素材后的效果记为未经干预的自动转换能力。
