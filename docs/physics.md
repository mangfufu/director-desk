# 物理与动作

在右侧「物理」启用对象效果，在「灯光与场景 → 物理场景」调整重力和地面。默认关闭。动态物体可调整质量、摩擦、弹性、阻尼、初速度与定时受力；有骨架的人形可以启用布娃娃。静态模式用于障碍，按路径运动模式用于推动其他物体。

「文件 → 新建」选择「动作与物理实验场」可播放 20 秒展示：人物动作（0–4 秒）、惯性对比（4–8 秒）、掉落和弹跳（8–12 秒）、奔跑与布娃娃（12–18 秒），最后以全景收尾。所有元素和参数都可编辑。

物理适用于掉落、抛掷、滚动、受力反应等，不限动作戏。内置人形与已完成骨架映射的导入人形支持布娃娃，其他模型使用整体刚体。手持与结构绑定对象先关闭物理再绑定。

新增人形动作：防御、出拳、踢腿、回旋踢、飞身踢、闪避、抛掷、推物、踉跄、翻滚。路径负责走位，动作负责姿态，物理开始后接管对象运动；布娃娃同时接管身体关节。拳脚没有自动命中判定，受力事件单独设置。

23 个默认人形动作采用手工编排的关节关键姿态，分别设计支撑、蓄力、伸展、回收与落地。关键姿态之间使用速度、加速度连续的五次曲线，动作衔接期间前后动作继续求值并混合；循环动作按速度播放，单次动作可在时间轴拉长或缩短。原有成品动作素材库与用户动作导入仍可使用。

人物白模重建了躯干、骨盆、渐细四肢、手掌与鞋形，采用平滑截面和连续法线，保留原骨架、比例调节、手持绑定及旧接拍姿态。标准成年人物约 6,800 个三角形，仍为 23 个网格；基础体型验收限制在 9,000 个三角形以内，不增加面部或手指动画。

物理采用 cannon-es（MIT），固定 120Hz 步长与插值输出，有 32MiB 帧缓存上限；缓存超出后回看较早时间会重新计算。预览、空间查询、截图、普通视频和深度视频使用同一求值入口。保存只存配置，关闭物理恢复原动作与路径。接拍冻结实际末帧后停用新段物理。

碰撞使用简化包围体：普通动态模型盒体／球体，等比例球体几何会自动识别为球形，其他模型仍可手动选择包围球。刚体围绕碰撞体中心旋转，保持模型原有编辑原点；球体使用实心球转动惯量，接触摩擦产生滚动，摩擦为零时允许滑动。静态布景可由子网格包围盒组成，复杂结构超过 127 个子网格时退回整体包围盒。因此精细凹面、高速小物体并非逐三角形碰撞。布娃娃是预演用关节近似，不是生物力学仿真。

接口及离线格式见 [物理参数](../skills/director-desk/references/physics.md)。

选中人物可显示关节节点，在布景窗口点击节点并旋转，或在动作栏选择关节调整 XYZ 度数。支持骨盆、躯干、头部、肩、肘、髋、膝和踝。偏移可记录为姿态关键帧，修改实时预览并支持撤销；节点只在布景中显示，不进入截图或参考视频。
