# 轻量视频反推

视频反推新增 `mediapipe` 引擎，新配置默认使用该方式；保留 `human3r` 标准识别和原工程格式。

- 设置入口：转换设置 → 识别方式 → 简易识别。最多识别人数 1–10，默认 3。
- 可选下载：固定版本 MediaPipe Tasks Vision 1.2.2 的 JS/WASM 和官方 Pose Lite 模型，约 21 MB，按 SHA-256 校验。与完整方案共享用户选定存储根目录，分别保存模型和运行组件。不安装 Python/CUDA，不修改 PATH。
- 推理：任务专用隐藏沙盒 renderer，CPU delegate。复用 MediaBunny 顺序解码，通过带随机路径的回环服务只读取当前视频及校验过的组件。暂停编辑界面不是推理前提，取消销毁任务 renderer 并关闭读取连接。
- 原始记录：`lite-frames.jsonl` 保留模型关键点；`lite-analysis.json` 记录时间、参数及处理说明；进度预览最多每秒两张，原始关键点每个分析帧保留。
- 程序后处理：屏幕位置匹配人物；过长失踪会新建身份；由三维关键点方向拟合骨骼旋转；画面横向位置近似映射到固定景深，脚底和画面高度估计垂直位置。不代表真实相机轨迹或真实世界走位，交叉遮挡可能串人。
- 工程：内嵌骨架 glTF 动作，使用现有 retarget 片段、路径和显示片段，可裁剪、调速、替换人物。固定参考机位；无场景恢复。单帧人物不生成动作资源，未识别到连续动作时明确失败。
- 自动能力区分：模型输出、程序拟合、人工修改分别记录；人工修正不能计作识别效果。开发样例与缓存放 `tmp/mediapipe-lite-test-20261110`，不进入发布包。

验证：`tests/reconstruction-lite.test.ts` 检查人物关联、拟合及可移植动作绑定；`scripts/test-reconstruction-lite.mjs` 验证真实安装、原始推理、进度预览、结果人物更换和打开工程。其默认样例路径仅用于本地开发，可通过 `DIRECTOR_LITE_VIDEO` 另传视频。

下载来源与哈希在 `desktop/video-reconstruction/lite-runtime.cjs`。组件项目为 https://github.com/google-ai-edge/mediapipe ，模型来源为 https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker 。

## 默认选择与安装

新配置默认简易识别，保存过的 engine 保留；旧配置已有 Human3R 许可记录时保留标准识别。设置顶部使用识别方式下拉框，简易识别标注默认，已就绪的方式追加已安装。选择后即时保存，下方仅显示所选方式的来源、设备要求、许可与下载；查看链接不切换方式，下载标准识别前须勾选同意许可。两种方式共用存储管理，来源与许可链接按各自模型打开。
